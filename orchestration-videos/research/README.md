# `research/` — the facts everything is built on

**What this is:** - `THREATS.md`: the 10 most-discussed threats, each paired with a real historical event (an "analog") whose speeds can be measured.
- `analogs/`: one data file per historical event, where every number has a source.
- `VIRAL_STRUCTURES.md`: research on what makes short videos get watched and shared, plus 18 story templates.

**Why it exists:** Every speed in every film comes from here, so the films are honest and checkable. The films never make up their own numbers.

**How common is this?** Common in data, science and journalism projects, usually called `data/` or `docs/`. It is rarer in ordinary apps.

**How other projects differ:** Data projects often split `data/raw/` (untouched downloads) from `data/processed/` (cleaned). Here the analog files already are the cleaned version, and their sources are listed inside them.
