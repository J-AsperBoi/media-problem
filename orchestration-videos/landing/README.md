# `landing/` — the web page the QR codes point to

**What this is:** A single draft web page (`index.html`). Every film ends with a QR code. Scanning it should open this page, with a tag saying which film sent the viewer.

**Why it exists:** It lets you measure which films actually drive sign-ups. **Not live yet:** `../config.json` still has a placeholder address.

**How common is this?** A separate folder for a website is common. Larger projects often keep the website in a completely separate repository.

**How other projects differ:** Real landing pages are usually hosted on a service such as GitHub Pages, Netlify or Vercel.
