# `fonts/` — typefaces

**What this is:** The two typefaces used in every film: Instrument Serif for titles and Patrick Hand for labels. The `CLAUDE.md` in here is a stray copy of the brief uploaded at the start; the real one is at [`../CLAUDE.md`](../CLAUDE.md).

**Why it exists:** Bundling fonts with the project means every computer renders the films identically.

**How common is this?** Common. Projects with visual output bundle their assets (fonts, images, sounds), usually in `assets/` or `public/`.

**How other projects differ:** Web apps often load fonts from a service like Google Fonts instead of bundling them.

**Learn more:** [Google Fonts: Instrument Serif](https://fonts.google.com/specimen/Instrument+Serif)
